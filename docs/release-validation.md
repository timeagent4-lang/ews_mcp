## 相对先前版本的修复

| 改动 | 结果与兼容影响 |
| --- | --- |
| HTML 回复/转发 | 支持新内容 HTML 片段，由 Exchange 添加原文；文本仍为默认。HTML 全文不能作为回复片段，`cid:` 不会自动创建附件。 |
| 忙闲查询 | 修复时区和未知数据判断，返回逐邮箱区间；`duration` 改为 `interval_minutes`，取消公共时段推荐，调用方需更新参数并自行选时段。 |
| 任务列表 | 先筛选未完成任务再分页，新增 `offset/has_more/next_offset`；保留原 `limit` 位置参数。 |
| 邮件旗标 | 完成时省略日期保留实际旧日期，确认/查询/重放回执一致；`clear` 携日期在读写前拒绝。 |
| 同步业务调用 | 放入 AnyIO 工作线程，避免阻塞事件循环；取消等待后用原 `operation_id` 查询，勿重新提交。 |
| 人员搜索 | `limit` 在 schema 和业务层均限定为整数 1–100；`auto` 的限制按每个来源计算。 |
| OA 异常响应 | JSON 顶层非对象返回 `OA_UNAVAILABLE`，不再泄漏成内部类型错误。 |
| 批量部分失败 | 确认/查询/重放均保留 `partial` 与逐项结果，返回 `ok=false/isError=true`；客户端须读取错误结果，只处理失败项。 |
| 精简 | 删除邮件镜像及未使用的 `tool_params.py`，精简 README/注释；回执数据库与附件缓存继续保留。 |

## 发布与支持边界

- 定义 32 项，公开注册 28 项（15 读、13 写）。`delete_draft/delete_messages` 按策略禁用；`get_oof_settings/set_oof` 因邮箱级权限和尚未修复的 SDK/配置问题禁用，未在本次启用。
- `EWS_MCP_SEND_ENABLED` 只限制真实发送和相应会议通知；不禁止草稿、联系人、任务或普通邮件旗标等无发送写入。附件下载另由 `EWS_MCP_DOWNLOAD_ENABLED` 控制。
- 不提供镜像/未回复判定、永久删除、跨任意邮箱或原始文件夹 ID 操作、联系人 Excel 批量导入、GAL 写入、任意附件上传；逐工具边界和原因见交付 Excel。
- `tools/list` 及调用方缓存需刷新，尤其是仅 LANID 必填的身份字段、忙闲参数与批量部分失败处理。Git 源码推送不等于内网容器已经部署。
- 本轮未验证真实 OA/Exchange 可达性、服务账号目录与邮箱权限、Outlook HTML 渲染或 Python 3.12 容器启动。内网仍需按目标部署提交执行上述测试和只读联调，再按授权安排实际写入验收。
